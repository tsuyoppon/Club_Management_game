# テストプレイ参加者向けプレイガイド（ドラフト）

このガイドは、ブラウザ版の「クラブ経営コンソール」でテストプレイに参加する人向けの基本マニュアルです。ゲームの勝ち方や推奨戦略ではなく、画面の見方、入力のしかた、試合・財務・各パラメーターの基本的な関係を説明します。

本ドラフトは、現在のリポジトリ実装に基づいています。スクリーンショットを差し込む前提で、各画面の説明見出しを用意しています。

---

## 1. ゲームの概要

プレイヤーはそれぞれ1つのクラブを担当し、8月から翌年7月までの12ターンでクラブを運営します。

主な流れは次の通りです。

1. 参加者がルームに入り、担当クラブを選ぶ
2. ホストがゲームを開始する
3. 各月ターンで、クラブごとに使う予算や一部の計画を入力する
4. 全クラブが入力を確定する
5. ホストがターンを締め切り、試合結果・財務・ファン・スポンサーなどを確定する
6. 各プレイヤーが結果を確認し、ackする
7. ホストが次ターンへ進める

シーズンは8月開始、翌年7月終了です。試合があるのは8月から5月までで、6月と7月は主にシーズン結果、賞金、翌期準備、情報公開の月です。

## 2. 初期設定と初期状態

### 2.1 参加人数とクラブ数

ブラウザ版では、ルーム作成時に2〜5クラブを設定します。初期表示のクラブ名は次の3つです。

- 東京ユナイテッド
- 大阪イレブン
- 福岡アローズ

ホストはルーム作成時にクラブ名を編集できます。クラブの短縮名は内部的に `C1`, `C2`, ... のように作られます。

### 2.2 シーズン開始時の主な初期値

シーズン1開始時、各クラブは同じ条件から始まります。

| 項目 | 初期値 |
|---|---:|
| 現金残高 | 100,000,000円 |
| スポンサー数 | 10社 |
| スポンサー単価 | 5,000,000円/社 |
| 当期強化費 | 30,000,000円/年 |
| アカデミー年予算 | 0円 |
| アカデミー累計投資 | 50,000,000円 |
| ファンベース | 10,000人 |
| スタッフ | 7区分それぞれ1人 |

スタッフ区分は `sales`, `hometown`, `operations`, `promotion`, `administration`, `topteam`, `academy` です。スタッフ年収は1人あたり4,800,000円で、月次では1人あたり400,000円の人件費として計上されます。

### 2.3 毎シーズンの月

| month_index | 表示月 | 主な意味 |
|---:|---|---|
| 1 | 8月 | シーズン開始、スポンサー収入・配分金、試合開始 |
| 2 | 9月 | 試合月、前期利益があれば税金支払い |
| 3 | 10月 | 試合月 |
| 4 | 11月 | 試合月、営業配分変更可能 |
| 5 | 12月 | 試合月、追加強化費入力可能、情報公開 |
| 6 | 1月 | 試合月、12月追加強化費の分割計上開始 |
| 7 | 2月 | 試合月、営業配分変更可能 |
| 8 | 3月 | 試合月 |
| 9 | 4月 | 試合月、スポンサー翌期内定進捗 |
| 10 | 5月 | 最終試合月、営業配分変更、スタッフ・アカデミー翌期計画 |
| 11 | 6月 | 賞金、翌期強化費入力、チーム力暫定公開 |
| 12 | 7月 | 翌期強化費入力、スポンサー翌期社数確定、移籍金判定、チーム力公開 |

## 3. 参加からゲーム開始まで

### 3.1 エントリー画面

**スクリーンショット差し込み: エントリー画面**

エントリー画面では、ゲームの再開、ルーム作成、招待コードでの参加ができます。

表示される主なエリアは次の通りです。

| エリア | 説明 |
|---|---|
| 続きから再開 | 過去に参加したゲームがある場合に表示されます。自分の担当クラブ、シーズン、現在月を確認して再開できます。 |
| ルーム作成 | ホストとして新しいゲームを作ります。表示名、ルーム名、クラブ名を入力します。 |
| 招待コード参加 | 参加者として既存ルームに入ります。表示名とホストから共有された招待コードを入力します。 |
| アーカイブ済み | ホストの場合、アーカイブ済みゲームの完全削除ができます。 |

ホストとして開始する場合は「ホスト表示名」「ルーム名」「クラブ枠」を入力し、「ホストとして開始」を押します。参加者として入る場合は「プレイヤー表示名」と「招待コード」を入力し、「ルームへ入る」を押します。

### 3.2 ロビー画面

**スクリーンショット差し込み: ロビー画面**

ロビーでは、各参加者が担当クラブを選び、準備完了状態にします。

| 表示項目 | 説明 |
|---|---|
| 招待コード | 他の参加者が入室するためのコードです。ホストが共有します。 |
| クラブ | このルームで使用するクラブ一覧です。 |
| 担当 | そのクラブを選択した参加者名です。未選択の場合は「未割当」と表示されます。 |
| 状態 | ready / waiting が表示されます。 |
| 参加者 | 入室中の参加者と、HOST / READY / WAIT の状態が表示されます。 |

参加者は担当するクラブの「担当する」を押した後、「readyにする」を押します。全クラブに担当者がいて ready になると、ホストが「ゲーム開始」を押せるようになります。

## 4. コンソール画面の共通構成

**スクリーンショット差し込み: コンソール全体**

ゲーム開始後は、クラブ経営コンソールでプレイします。

画面上部には、ルームコード、シーズン番号、ターン状態が表示されます。ターン状態は主に次のように変わります。

| 状態 | 画面表示 | 意味 |
|---|---|---|
| `open` / `collecting` | 入力受付 | プレイヤーが入力できます。 |
| `locked` | 締切 | 入力が締め切られ、ホストの結果計算待ちです。 |
| `resolved` | 結果確認 | 試合・財務などが確定済みで、各プレイヤーが結果確認します。 |
| `acked` | 画面上では次ターンへ進行後に見えなくなる状態 | そのターンの確認が完了した状態です。 |

左側のナビゲーションで画面を切り替えます。

| タブ | 内容 |
|---|---|
| Turn | 当月の入力、確定、結果確認を行うメイン画面 |
| Matches | 自クラブの試合日程・結果・入場者数・天気 |
| Table | 現シーズン順位表、確定済みシーズンの最終順位表 |
| Finance | 自クラブの月次・累計財務 |
| Fans | 各クラブの公開フォロワーとファンベース |
| Sponsors | 自クラブの現在スポンサー数と翌期確定見込み |
| Staff | 自クラブのスタッフ人数と来季予定 |
| Team Power | 公開済みのチーム力指標 |
| Disclosures | 12月以降に公開される全クラブ財務概要 |

右側には「対戦進捗」と「ホスト操作」が表示されます。ホストでない参加者は、ホスト操作欄には説明のみが表示されます。

## 5. ターン進行の基本

### 5.1 プレイヤーの操作

**スクリーンショット差し込み: Turnタブ**

各月、プレイヤーは Turn タブで表示された入力項目を入力します。入力内容は自動で下書き保存されます。

入力が終わったら「入力を確定」を押します。確定後は、ホストが締め切るまで待ちます。

結果が確定すると、Turn タブに「結果を確認して ack」ボタンが表示されます。Matches、Finance、Table などの結果を確認したら ack してください。

### 5.2 ホストの操作

ホストは全体進行を管理します。

| ボタン | 押せる条件 | 処理内容 |
|---|---|---|
| open | 現在ターンが open のとき | 入力受付状態にします。 |
| lock | 全クラブが commit 済みのとき | 入力を締め切ります。 |
| resolve | lock 済みのとき | 試合、財務、ファン、スポンサー、公開情報などを確定します。 |
| advance | 全クラブが ack 済みのとき | 次の月へ進めます。 |
| 解除 | lock 前で、対象クラブが commit 済みのとき | そのクラブの確定を解除します。 |
| アーカイブ | いつでも | ゲームを再開一覧から非表示にします。 |

全クラブが入力確定しないと lock できません。全クラブが ack しないと advance できません。

## 6. 毎月入力する項目

Turn タブには、その月に入力できる項目だけが表示されます。表示されていない項目は、その月には入力できません。

### 6.1 毎月入力できる費用

| 項目 | 内容 | 財務上の扱い |
|---|---|---|
| 営業費 | スポンサー営業に使う費用です。 | 入力月の費用として計上されます。スポンサー翌期社数に影響します。 |
| プロモーション費 | ファンベースに影響するプロモーション費です。 | 入力月の費用として計上されます。ファンベース更新に影響します。 |
| ホームタウン活動費 | ファンベースに影響する地域活動費です。 | 入力月の費用として計上されます。ファンベース更新に影響します。 |

### 6.2 条件付きで入力できる項目

| 項目 | 入力できる月・条件 | 内容 |
|---|---|---|
| 新規スポンサー営業配分 | 8月、11月、2月、5月 | 営業努力のうち、新規スポンサー向けに配分する割合です。0〜1で入力します。デフォルトは0.5です。 |
| 翌月ホーム向けプロモ | 翌月に自クラブのホーム戦がある月 | 翌月のホームゲーム入場者数に影響するプロモーション費です。費用は入力月に計上されます。 |
| 追加強化費 | 12月のみ | 当シーズン中に追加する強化費です。1月〜7月に分割して費用計上され、チーム力にも反映されます。債務超過中は入力できません。 |
| 来期強化費 | 6月、7月 | 次シーズンの当期強化費として使う予算です。6月と7月の入力合計が次シーズンに引き継がれます。 |

金額項目は円単位です。営業配分だけは割合で、0がすべて既存スポンサー向け、1がすべて新規スポンサー向けです。

### 6.3 5月イベント: スタッフ計画とアカデミー予算

**スクリーンショット差し込み: 5月イベント表示**

5月には、通常入力に加えて「来季スタッフ計画」と「翌年度アカデミー予算」を設定できます。

スタッフ計画では、各スタッフ区分の来季目標人数を保存します。人数を増やす場合は採用予定、減らす場合は解雇予定として扱われます。スタッフ人数の反映は次シーズン8月です。解雇予定がある場合、7月に退職金が費用計上されます。

アカデミー予算は、次シーズンの年予算として保存されます。次シーズンでは12分割で月次費用になり、アカデミー累計投資に積み上がります。

## 7. 試合ルール

### 7.1 試合日程

**スクリーンショット差し込み: Matchesタブ**

試合は8月から5月までの10か月に組まれます。クラブ数に応じて、月によっては bye が表示されることがあります。

Matches タブでは次の情報を確認できます。

| 表示項目 | 説明 |
|---|---|
| 月 | 試合月です。 |
| H/A | ホームなら H、アウェイなら A、試合なしなら bye です。 |
| 相手 | 対戦相手です。 |
| 状態 | scheduled または played です。 |
| 結果 | 自クラブから見たスコアです。 |
| 入場者数 | ホーム・アウェイ合計の入場者数です。 |
| 天気 | sunny / cloudy / rain のいずれかです。 |

### 7.2 試合結果の決まり方

試合結果は、ホストが resolve を実行したタイミングで月ごとに確定します。細かい確率式は画面には表示されませんが、主に次の関係があります。

- チーム力が高いほど、試合上有利になります。
- ホームクラブにはホーム補正があります。
- 直近の連勝・連敗は有効レーティングに少し影響します。
- 勝敗だけでなく、スコアも確定します。
- 同じ fixture と turn に対しては、実装上のシードにより再現性のある結果になります。

### 7.3 チーム力

チーム力は、主に強化費とアカデミー累計投資から計算されます。トップチームスタッフ数が強化費規模に対して不足している場合は、チーム力にペナルティがかかります。

チーム力そのものは常に全詳細が公開されるわけではありません。Team Power タブでは、公開イベント後に全クラブのチーム力指標を確認できます。

公開タイミングは次の通りです。

| 月 | 内容 |
|---|---|
| 12月 | チーム力指標が公開されます。 |
| 6月 | 6月入力ベースの暫定チーム力指標が公開されます。 |
| 7月 | 次シーズン予測のチーム力指標が公開されます。 |

### 7.4 順位表

**スクリーンショット差し込み: Tableタブ**

勝点は、勝ち3、引き分け1、負け0です。順位は基本的に次の順で決まります。

1. 勝点
2. 得失点
3. 得点
4. 直接対戦成績

債務超過による勝点ペナルティがある場合は、順位表計算時に反映されます。ペナルティ反映後の勝点は0未満にはなりません。

シーズン終了後、最終順位表は保存されます。Table タブの「シーズン別最終順位表」では、確定済みシーズンを選んで確認できます。

## 8. 入場者数・ファン

### 8.1 入場者数

ホームゲームの入場者数は、ホームクラブのファンベース、相手クラブのファンベース、天気、現在順位、過去成績、前月に入力した「翌月ホーム向けプロモ」、開幕・最終戦イベントの影響を受けます。

スタジアム上限は20,000人です。アウェイ客にも上限があり、総入場者数が上限を超える場合は調整されます。

### 8.2 Fansタブ

**スクリーンショット差し込み: Fansタブ**

Fans タブでは、全クラブの公開フォロワーとファンベース count を確認できます。

| 表示項目 | 説明 |
|---|---|
| 公開フォロワー | ファンベースをもとにした公開指標です。誤差とトレンド影響を含みます。 |
| ファンベース count | 実装上のファンベース人数です。 |

ファンベースは、プロモーション費、ホームタウン活動費、promotion / hometown スタッフ、成績、過去成績の影響を受けて毎月更新されます。ホームタウン活動費は、前月からの変動が大きい場合に伸びが抑えられる処理があります。

## 9. スポンサー

### 9.1 Sponsorsタブ

**スクリーンショット差し込み: Sponsorsタブ**

Sponsors タブでは、自クラブのスポンサー状況を確認できます。

| 表示項目 | 説明 |
|---|---|
| 現スポンサー数 | 当シーズンのスポンサー社数です。 |
| 翌期確定見込み | 4〜6月の内定進捗などで確定した翌期スポンサー数です。 |

### 9.2 スポンサー収入

スポンサー収入は8月に一括入金されます。

計上額は「現スポンサー数 × スポンサー単価」です。初期状態では10社 × 5,000,000円なので、シーズン1の8月に50,000,000円がスポンサー収入として計上されます。

### 9.3 翌期スポンサー社数

翌期スポンサーは、既存スポンサーの継続と新規スポンサーの獲得に分かれます。

おおまかな関係は次の通りです。

- 営業費と sales スタッフはスポンサー営業努力に影響します。
- 営業配分で、営業努力を既存スポンサー向けと新規スポンサー向けに分けます。
- 成績、公開フォロワー、ファン成長もスポンサー見込みに影響します。
- 4月、5月、6月に翌期スポンサーの内定進捗が発生します。
- 7月に翌期スポンサー社数が最終確定します。
- 次シーズンは、前シーズンで確定したスポンサー社数から始まります。

## 10. 財務

### 10.1 Financeタブ

**スクリーンショット差し込み: Financeタブ**

Finance タブでは、自クラブの財務状況を確認できます。

上部には、対象月、期首残高、期末残高が表示されます。下には「今月の収支」と「今シーズン累積の収支」が表示されます。

「月次財務推移」を押すと、8月から7月までの費目別推移、収入合計、費用合計、純収支、現金残高を一覧できます。

### 10.2 主な収入

| 収入 | 計上タイミング | 概要 |
|---|---|---|
| スポンサー収入 | 8月 | スポンサー社数 × 5,000,000円を一括計上します。 |
| 配分金 | 8月 | 20,000,000円を一括計上します。 |
| 入場料収入 | ホームゲーム月 | 総入場者数 × チケット単価で計上します。現行の実装上のチケット単価は2,000円です。 |
| 物販収入 | ホームゲーム月 | 総入場者数 × 800円で計上します。 |
| 賞金 | 6月 | 5月までの最終順位に応じて計上します。1位20,000,000円、2位10,000,000円、3位5,000,000円です。 |
| アカデミー移籍金 | 7月 | アカデミー累計投資に応じた確率で発生します。発生時は50,000,000〜200,000,000円です。 |

### 10.3 主な費用

| 費用 | 計上タイミング | 概要 |
|---|---|---|
| 強化費 | 毎月 | 当期強化費を12分割で計上します。初期値30,000,000円/年の場合、月2,500,000円です。 |
| 追加強化費 | 1月〜7月 | 12月に入力した追加強化費を7分割で計上します。 |
| トップチーム運営経費 | 毎月 | 当月強化費の10%です。 |
| スタッフ人件費 | 毎月 | スタッフ人数 × 400,000円/月です。初期状態では7人なので2,800,000円/月です。 |
| アカデミー運営経費 | 毎月 | 当期アカデミー年予算を12分割で計上します。シーズン1初期値は0円です。 |
| 管理運営経費 | 毎月 | 3,000,000円/月です。 |
| 試合関連経費 | ホームゲーム月 | ホームゲーム1試合あたり3,000,000円です。 |
| 物販原価 | ホームゲーム月 | 物販収入の60%です。 |
| 入力費用 | 入力月 | 営業費、プロモーション費、ホームタウン活動費、翌月ホーム向けプロモは入力月に費用計上されます。 |
| 税金 | 9月 | 前シーズン利益がある場合、その33%を支払います。シーズン1では前シーズンがないため通常は発生しません。 |
| スタッフ退職金 | 7月 | 5月にスタッフ削減を予定した場合、削減人数 × 年収 × 0.75 が計上されます。 |

### 10.4 現金残高と債務超過

毎月の resolve 時に、その月の収入と費用が台帳に追加され、月次スナップショットが作られます。

現金残高がマイナスになると、そのシーズンで債務超過状態になります。債務超過になると次の影響があります。

- 勝点-10のペナルティがシーズン内で一度だけ適用されます。
- 12月の追加強化費を入力できなくなります。

勝点ペナルティ適用後の勝点は0未満にはなりません。

### 10.5 公開財務情報

**スクリーンショット差し込み: Disclosuresタブ**

Disclosures タブでは、12月ターン終了後に、前シーズン末の全クラブ財務概要が公開されます。

公開される項目は、スポンサー収入、入場料収入、配分金、賞金、物販収入、移籍金収入、収入合計、強化費、試合関連経費、トップチーム運営経費、アカデミー運営経費、物販原価、人件費、費用合計、純利益、期末残高です。

## 11. スタッフとアカデミー

### 11.1 Staffタブ

**スクリーンショット差し込み: Staffタブ**

Staff タブでは、自クラブのスタッフ人数と来季予定を確認できます。

| 表示項目 | 説明 |
|---|---|
| 区分 | スタッフの役割です。 |
| 現在人数 | 現シーズンに有効な人数です。 |
| 来季予定 | 5月に保存した来季目標人数です。未入力の場合は `-` です。 |

スタッフ人数は、営業、ファンベース、チーム力などに影響します。現行実装では、採用は次シーズン8月に目標人数まで反映されます。解雇予定は次シーズン8月に反映され、7月に退職金が計上されます。

### 11.2 アカデミー

アカデミーは、年予算を設定すると次シーズンから毎月費用として計上され、累計投資に積み上がります。

アカデミー累計投資はチーム力に影響します。また、7月にはアカデミー移籍金収入が発生する可能性があります。移籍金の発生確率は累計投資が大きいほど上がりますが、上限があります。

---

## 12. Team Powerタブ

**スクリーンショット差し込み: Team Powerタブ**

Team Power タブでは、公開済みのチーム力指標を確認できます。公開前は「7月ターン終了後または12月ターン終了後に、全クラブのチーム力指標が公開されます。」という案内が表示されます。

公開後は、順位、クラブ名、チーム力が一覧表示されます。自クラブの行は強調表示されます。

チーム力は、強化費、過去の強化費、アカデミー累計投資、トップチームスタッフ体制などから計算されます。試合結果に影響しますが、試合結果はチーム力だけで決まるわけではなく、ホーム補正や直近成績も影響します。

## 13. ゲームの保存・再開・終了

ゲーム進行はデータベースに保存されます。ブラウザを閉じても、同じ環境であればエントリー画面の「続きから再開」から戻れます。

ホストはゲームをアーカイブできます。アーカイブすると通常の再開一覧からは非表示になります。アーカイブ済みゲームは、ホストが確認コードとして招待コードを入力することで完全削除できます。完全削除したゲームは復元できません。

7月ターンを advance すると、シーズンが確定し、次シーズンが自動作成されます。次シーズンには、スポンサー社数、ファンベース、アカデミー累計投資、翌期強化費、翌年度アカデミー予算などが引き継がれます。

## 14. プレイ中によく見るメッセージ

| メッセージ | 意味 |
|---|---|
| 未確定のクラブがあります。 | 全クラブが入力確定していないため、ホストが lock できません。 |
| 未ackのクラブがあります。 | 全クラブが結果確認していないため、ホストが advance できません。 |
| この操作はホストだけが実行できます。 | lock / resolve / advance などはホスト専用です。 |
| このターンの入力は締め切られています。 | lock 後は入力を変更できません。 |
| 確定前に入力を保存してください。 | 入力内容が空のまま確定しようとしています。 |
| このターンでは入力できない項目が含まれています。 | 月や条件に合わない入力項目が送信されています。画面を更新して再入力してください。 |
| 結果確定前はackできません。 | resolve 前なので結果確認はまだできません。 |
| 入力確定の解除は締切前だけ実行できます。 | lock 後はホストでも commit 解除できません。 |

## 15. スクリーンショット差し込み候補

正式版では、次のスクリーンショットを入れると参加者が理解しやすくなります。

- エントリー画面: 再開、ルーム作成、招待コード参加
- ロビー画面: クラブ選択、ready、ゲーム開始
- コンソール全体: ヘッダー、左タブ、右側の進捗・ホスト操作
- Turnタブ: 通常入力、下書き保存、入力確定
- 5月イベント: スタッフ計画、アカデミー予算
- Matchesタブ: 日程、H/A、結果、入場者数、天気
- Tableタブ: 現順位表、シーズン別最終順位表
- Financeタブ: 今月の収支、累計収支
- 月次財務推移: 費目別の月次一覧
- Fansタブ: 公開フォロワー、ファンベース
- Sponsorsタブ: 現スポンサー数、翌期確定見込み
- Staffタブ: 現在人数、来季予定
- Team Powerタブ: 公開前表示、公開後一覧
- Disclosuresタブ: 全クラブ財務概要
