# Result PDF font

`NotoSansJP-Variable.ttf` is Noto Sans Japanese from the Google Fonts project.
It is embedded as a subset in generated game-result PDFs. The font is distributed
under the SIL Open Font License 1.1; see `OFL.txt` in this directory.

Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
